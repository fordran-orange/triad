# Triad product map

The canonical product map is derived from the three independent `ProductInspection` records in PostgreSQL and displayed at `/triad/development` → Product map. Each area retains its inspector, evidence and assessment; differing judgments are not flattened into an invented consensus.

The first inspection has not yet completed. This file is updated with its actual evidence after the real cycle. Core administration is shared infrastructure, not a Triad product feature.
