# Agent boundaries

Triad has three independent decision roles, to be specified by human intent later.
No model vendor, trading hypothesis, indicator or strategy is selected by this setup.
Optional local Qwen support is a worker/helper, never a fourth deciding member.
All tools will be mediated by runtime policy. Agents can request authority changes;
only authenticated human-approved control-plane workflows may grant them.
No agent runtime or trading execution is installed on Day 1.
