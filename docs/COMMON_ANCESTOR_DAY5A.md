# Common ancestor
The completed, tested Day-5A working implementation is the common ancestor of Core, P2P and Triad. The permanent tag base/day5a-complete preserves code; the pre-split baseline report identifies separately restored database/artifact snapshots.

One monorepo integration lineage is retained. Ownership lives in packages and enforced interfaces, not permanently divergent copies. The final base/trading-core-v1 tag is created only after extraction acceptance.
