# Research method review

Each run creates an immutable scoped WorkItem, Control Plane decision, journal and handoff before review. The packet includes hypothesis link, dataset/quality, strategy/source identity, parameters, costs, fills, metrics, ledger and equity artifacts. Reviewers can inspect everything through the API/UI. Logical worker/reviewer roles are distinct; fixture execution does not claim those cloud models were called.

The supplied independent host verifier loads original dataset evidence, reruns the deterministic engine, verifies content and artifact hashes, and records ACCEPT_RESULT, REQUEST_RERUN or DATA_QUALITY_FAILURE plus a canonical Day 2 Review and journal. Its mode is explicitly HOST_VERIFIER_NOT_MODEL. ACCEPT_RESULT means this fixture's method/result reproduced; it is not endorsement of strategy merit. The authenticated POST `/api/research/runs/<id>/method-review` accepts all six method verdicts: ACCEPT_RESULT, REQUEST_RERUN, REJECT_METHOD, DATA_QUALITY_FAILURE, LOOKAHEAD_RISK and INCONCLUSIVE. Submit a decision, nonempty findings and evidence_checked lists, and a tests_repeated list (empty means no tests repeated). It records HUMAN_OPERATOR_METHOD_REVIEW with the assigned reviewer role, canonical Review and journal; it never claims model inference. It only accepts work awaiting review, prevents overwriting prior review, honors the kill switch, and sends all non-acceptance verdicts to CHANGES_REQUESTED. No human reviews were fabricated in the production mission; rejection/authentication are exercised only in disposable integration tests. Current review does not claim a second independently implemented backtest engine.

Qwen can be requested through authenticated `/api/research/runs/<id>/support`. It uses the existing capability router, parent WorkItem, depth/count limits and shared model budgets to summarize bounded operational metadata. It may not declare a strategy successful. The recorded mission needs no Qwen or cloud calls; evidence-based deterministic checks establish its narrow conclusion.


Review metadata, canonical Review/journal records, work transitions and outbox events now commit in one PostgreSQL transaction for both host and human review. The authority gate serializes cancellation; optimistic work revisions reject stale concurrent reviewers and roll back their entire verdict. Portable review.md remains a projection of authoritative records.
