# Aegis Optimization Lab v2, Phase 2: the trial store and query layer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Lab a trial store that scales to a million trials and a query layer the browser reads instead of chunk files: layout 2 (trial numbers, positions, `param_key`, `design`, `block`, status and attempt), compaction into parts with a manifest, snapshots as immutable file sets with retention and reclamation, pinned data and engine provenance on new experiments with a provenance-checked resume, a 400 MB column cache, the `/aegis/api/lab` summary / query / trials routes with bounded views (counts, matrix exact + aggregate, page, top, marginals, parallel bundles) and the optimizer source adapter; Phase 2b's per-trade Sharpe beside the metrics and the DSR functions with their reference tests; Phase 2c's vertical slice on a real 12,000-trial experiment through canvas charts; the scratch worker harness that keeps every test out of `C:\Triad\data\aegis`; the Track A / Track B benchmark records; and the walk items that prove it.

**Architecture:** A new Aegis-owned package `app/products/aegis/lab/` (`policy.py` constants, `identity.py` keys and `engine_build`, `sharpe.py`, `store.py` reader / compaction / snapshots / reclamation, `cache.py`, `query.py` pure views over Arrow columns, `sources.py` for `exp:` and `opt:` sources) consumed by `experiments.py` (layout-2 write path, F16 chunk naming, additive document fields) and by a Lab block of routes in `api.py`. The reader serves layout 1 and layout 2 through one code path; legacy experiments are never rewritten. `backtest._side_metrics` returns the kernel's `ret` view as a fourth value and `run_metrics` adds `lab_metrics` only when asked, so no `result_hash` moves. The UI replaces `useLabSource`'s experiment fetches with a `/lab` query hook that feeds the same `LabData` consumers, draws the heatmap and the parallel coordinates on canvas behind one primitive module, and keeps every decision in pure `.ts` modules under vitest. Browser evidence comes from a scratch worker on port 8103 started from this checkout with `AEGIS_DATA_ROOT` pointing at a scratch root.

**Tech Stack:** Python 3.12, FastAPI, pydantic v2, pyarrow 23 (zstd, dictionary and fixed-size-binary columns), numpy, numba kernel (unchanged); React 18, TypeScript, Vite 5, Canvas 2D, vitest (node, `src/**/*.test.ts`), Playwright walk `tests/products/aegis/browser_workstation.py`; PowerShell 7 for the scratch launcher. No new dependency.

**Spec:** `docs/AEGIS_OPTIMIZATION_LAB_V2_IMPLEMENTATION_PLAN.md` — §5 conventions (panel states, the selection model, `Linked · k filters`), §5.1 (dock `n` badge, hatch, legend, mode chip), §5.2 (Screen B data sources), §5.10 (the Lab API), §6.1–6.4 (identity, manifest fields, the layout-2 row, the counts and their invariants), §7.1 (exact slice), §7.2 (aggregated projection), §7.3a (evaluation identity and canonicalization), §7.8 (linked filtering, `filter_hash`), §7.9 (parallel bundles), §7.12 (trade Sharpe and DSR with the fourteen reference cases), §9.1c (measured vs estimated, re-test triggers), §9.2–9.8 (storage, paging bounds, snapshots, budgets §9.6a / §9.6b, the no-million-node rule, the synthetic and real fixtures, the scratch harness), §11 Phase 2 row with 2b and 2c, §11.1, §12 (QA register, charting criteria, dependency verdicts), §15 rows 1–4, 7, 9, 11, 14, 24, 27, 30, §16 R2.5 and R3, §18–§22 rulings (R2, R6, R7, R-9, R-10, R-14, Codex round 2 item 7, §19 code boundaries, §20 storage and performance tests, §22 approvals). ## Review Focus

1. **The worker restarts in the middle of compaction**, leaving a part file, a manifest from before or after it, and chunk files that overlap the part. Expected: the reader takes the manifest's parts plus every chunk not listed as merged, collapses copies of the same `(trial_no, block, attempt)` and counts them as `duplicates`; no trial is lost or double-counted; re-running compaction is idempotent and leaves one generation. Test: `tests/test_lab_store.py::test_lab_compaction_torn_is_idempotent`.
2. **A filter that leaves zero trials, or a heatmap axis with one value.** Expected: every view answers with an explicit empty state naming the filter scope (`no trials match: 1 filter active`), a 1 × n matrix renders, no division by zero in a colour scale. Tests: `tests/test_lab_query.py::test_lab_query_empty_scope`; vitest `labHeatmap.test.ts::empty` and `::one axis`.
3. **A metric that is undefined for some trials** (`cagr` / `mar` below a year, `profit_factor` without losses, `sharpe_trade` below 2 trades). Expected: null-valued trials are counted as `undefined` in the scope, never ranked as zero, listed last under that sort, never coloured. Test: `tests/test_lab_query.py::test_lab_undefined_metric_counts`.
4. **A layout-2 experiment resumed after the engine source changed or the archive vintage moved.** Expected: `POST /experiments/{id}/resume` answers 409 naming the drift (`data drift: …` or `engine build drift (document …, worker …)`), the document is unchanged, and a legacy experiment still resumes through today's re-selection. Tests: `tests/test_lab_store.py::test_resume_refuses_engine_build_drift`, `::test_resume_refuses_vintage_drift`, `::test_legacy_resume_unchanged`.
5. **Reclamation while a snapshot is open** (a reader holds generation g while generation g + 1 lists g's chunks as merged and the retention window has passed). Expected: files referenced by an open snapshot are never reclaimed, the older snapshot reopens identically, and once the registry is lost (a restart) a snapshot whose files are gone is reported as `snapshot expired`, never served partially. A reader that holds a merged chunk open without the registry (Windows refuses the unlink while the handle is open, and `_retry` re-raises after 50 × 10 ms, runs.py:227-236): `reclaim` leaves that chunk listed for the next pass and never raises, so `run_unit` never reaches jobs.py:152-153's `failed`. Tests: `tests/test_lab_store.py::test_reopen_older_snapshot_after_later_generations`, `::test_readers_see_one_set_during_compaction`, `::test_snapshot_expired_after_registry_loss`, `::test_reclaim_skips_a_held_chunk_without_failing`.
