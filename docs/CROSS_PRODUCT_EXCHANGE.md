# Cross-product exchange
Exchange is CLOSED by default. No import endpoint, automatic graph traversal, shared-agent memory feed or cross-product context export is enabled.

Future reviewed candidates must identify origin, destination, immutable source record/version, evidence references, provenance, content digest and an explicit human approval. Approval of a knowledge transfer cannot expand execution authority. Shared infrastructure fixes do not automatically transfer strategic conclusions.

Human-authored combined notes are for the operator. They are not automatically admitted to either product's agent context.
