# Day7 lifecycle timestamps — bounded build

Builder /root. New WorkItems persist updated_at at creation; transitions record real update/start/completion/closure times. Failed attempts retain completion but remain reopenable; restart clears old completion/closure. New Handoffs record creation/send at persistence. Host dispatch to the assigned reviewer records receive/acknowledgment, and persisted review/QA records completion. These are append-only HandoffLifecycle events: the read projection overlays fields without editing the original handoff. Duplicate acknowledgments retain the first observed time. Foreign receivers are rejected.

All typed Record datetime fields reject naive timestamps and normalize aware values to UTC. Existing absent times remain unknown rather than being filled with the current time. ImplementationRun/QARun have optional explicit start/completion fields populated from linked actual work start and host completion ingestion. AgentCreationRequest stores requested_at; generated QualityDebt stores creation/update times. Provider verification already records actual start/completion. Cycle/integration/merge/debt-resolution times will be covered by their later Day7 segments.
