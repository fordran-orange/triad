# G: Core integration UI

/core/integrations separates external connections from AI providers, with category filtering, readable capability/setup details, explicit unconfigured broker shells, local data coverage matching and governed candidate submission/review. No unsupported broker Configure/Test/login controls exist. Local catalog checks clearly differ from account tests. Mutations reuse existing operator authentication and origin restrictions; token is held only in page memory. Provider/candidate text is rendered with textContent and shared human-readable record presentation. Match is read-only; no source acquisition, paid fallback or live execution endpoint is exposed.

Root API/surface checks cover authentication, discovery, empty real-data coverage and honest shell navigation. Live browser checks follow reviewed deployment.
